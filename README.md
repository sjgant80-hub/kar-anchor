# Kar-Anchor

**Live:** https://sjgant80-hub.github.io/kar-anchor/

A sovereign Merkle anchor for AI-generated content. Commit a batch of text items to one Merkle root
you can publish anywhere; each item gets an inclusion proof anyone can re-check offline. No backend,
no server, nothing sent anywhere — one HTML file, in your browser.

A root proves an item was in the committed set and is unaltered. It does not prove authorship, nor the
time it existed unless the root was published somewhere public.

Built by **Kar** for AI Native Solutions.
